# BRANDING_MIGRATION.md — "Tournatak" → "Bracketa"

Living checklist for the full, non-breaking rebrand. Scope is **strictly branding /
copy / assets** — no business logic, schema, scoring, permissions, or test behavior
changes. Follows the standard pattern used in `TASKS.md` / `PROJECT_CHECKLIST.md`.

---

## Rules applied

- Do **not** touch migrations, seeders, model logic, routes, or permissions.
- Do **not** rename namespaces / repo folder (`App\` stays `App\`; the local folder
  stays `tournatak-laravel`). This is a display-name change.
- Update test assertions that embed "Tournatak" **only** if found — flagged below for review.
- Comments / historical docs referencing the old repo name are left alone.
- Infra identifiers (docker compose names, CI test DB, CSS class `.swal-tournatak`,
  seeder emails) are **out of scope** — see "Intentionally NOT changed" below.
